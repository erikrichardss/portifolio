Portfólio Pessoal
Portfólio pessoal construído para apresentar minha trajetória, habilidades e projetos como desenvolvedor web. O projeto foi desenvolvido com foco em performance, responsividade e interatividade, utilizando exclusivamente tecnologias web nativas.

Tecnologias:
HTML5
CSS3
JavaScript

Funcionalidades
Interface moderna e adaptável a diferentes tamanhos de tela (responsiva).

Sistema de alternância de tema (Light/Dark Mode) com persistência de dados via localStorage.

Fundo interativo e animado desenvolvido com a API do HTML5 Canvas.

Navegação fluida entre as seções (Início, Sobre, Habilidades, Projetos e Contato).
